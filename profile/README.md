#  GastroMatch

### Cozinhe o que você já tem em casa.

Plataforma gastronômica que conecta **receitas, chefs, restaurantes e nutricionistas**.<br />
Explore sem cadastro, siga o passo a passo e descubra quem cozinha por trás de cada prato.

## O que o GastroMatch faz

| | |
|---|---|
| 🧊 **Na geladeira** | Escolha os ingredientes que você tem e veja as receitas que cabem neles. |
| 📖 **Passo a passo guiado** | Etapas em ordem, com cronômetro, vídeo e dicas de chefs. |
| 👨‍🍳 **Chefs, nutricionistas e restaurantes** | Diretório de profissionais com perfil e links de contato. |
| 🥗 **Tabela nutricional** | Estimativa por porção, calculada a partir dos ingredientes. |

## Como contribuir

1. Veja as issues abertas no [quadro do projeto](https://github.com/orgs/GastroMatch-PI/projects/1).
2. Crie sua branch a partir da `develop` e abra um pull request.
3. A `main` recebe só o que já passou pela `develop`.
